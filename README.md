# nxt-ui-atlas-link

Aplicación Next.js de Atlas Link. Contiene la landing y los portales de hospital, administración y aseguradora.

Para el arranque integrado, clona el workspace con `git clone --recurse-submodules https://github.com/jesusfranck09/atlas-link.git`. Desde `frontend/nxt-ui-atlas-link`: `npm ci`, luego usa los comandos documentados en el README del workspace.
